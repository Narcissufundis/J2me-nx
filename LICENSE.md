## 为什么是这个许可证 / Why this license

- 虚拟机 [PluotSorbet](https://github.com/mozilla/pluotsorbet) 与其使用的 phoneME 类库
  （CLDC/MIDP，来自 Sun/Oracle）是 GPL-2.0（Java 部分带 Classpath 例外）；
  本项目包含它们的源码并做了补丁，因此整体按 GPL-2.0 兼容方式发布最自然。
- PluotSorbet and the phoneME class libraries it builds on (CLDC/MIDP, originally from
  Sun/Oracle) are GPL-2.0 (with the Classpath exception for the Java parts). This repository
  contains and patches that code, so GPL-2.0-compatible terms are the natural choice.
